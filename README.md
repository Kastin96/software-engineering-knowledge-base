# Software Engineering Knowledge Base

This repository is a personal software engineering knowledge base.

It currently contains two main types of material:

- structured knowledge-base learning paths;
- interview preparation notes and assessment-style practice.

The current focus is JavaScript, TypeScript, core Java, Java Spring, and
reactive Java. The materials are written as practical Markdown notes with
explanations, code examples, common mistakes, practice tasks, interview-style
questions, exercises, and cheatsheets.

## Knowledge Base

- [Java Learning Path](knowledge-base/java/README.md)
- [Java Reactive Learning Path](knowledge-base/java-reactive/README.md)
- [Java Spring Learning Path](knowledge-base/java-spring/README.md)
- [JavaScript Learning Path](knowledge-base/javascript/README.md)

The `knowledge-base/java` section is a structured Java Core learning path. It
covers language basics, OOP, collections and data structures, exceptions and
debugging, generics, functional Java, concurrency, I/O and serialization, JVM and
build tools, testing, patterns and best practices, practical examples,
exercises, and cheatsheets.

The `knowledge-base/java-reactive` section is a practical learning path for
concurrency, asynchronous programming, and reactive Java. It starts with the
differences between concurrency, async, and reactive models, then is intended to
grow into threads, executors, futures, `CompletableFuture`, virtual threads,
Reactive Streams, Project Reactor, WebFlux, WebClient, reactive data access,
testing, and production pitfalls.

The `knowledge-base/java-spring` section is a practical Spring backend learning
path. It covers Spring Core and dependency injection, Spring Boot, REST APIs,
validation, error handling, SQL and NoSQL data access, transactions, WebFlux
basics, AOP, security, logging, actuator, testing, messaging, production
support, architecture, practical examples, exercises, and cheatsheets.

The `knowledge-base/javascript` section is a structured JavaScript learning
path. It covers language basics, core concepts, data structures, async
JavaScript, browser JavaScript, Node.js JavaScript, error handling and
debugging, modern JavaScript, patterns and best practices, testing, practical
examples, exercises, and cheatsheets.

## Interview Preparation

The repository is intended to grow into a broader software engineering reference.
Likely future areas include databases, backend engineering, system design,
DevOps, interview preparation for Java backend roles, and project-based
