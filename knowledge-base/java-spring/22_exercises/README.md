# Exercises

This section contains practice tasks for Spring Boot backend development.

Each exercise is designed to be implemented in code. The goal is to practice
real backend decisions: validation, data access, security, testing, reactive
flows, messaging, and production support.

## How To Work Through

Implement one exercise at a time. For each one, write down:

- requirements;
- chosen Spring components;
- expected tests;
- production risks;
- trade-offs.

## Mini Goal

By the end of this section, you should be able to build and explain a compact
Spring Boot service under interview or assessment conditions.
