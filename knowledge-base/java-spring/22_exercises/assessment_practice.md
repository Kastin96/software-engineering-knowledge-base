# Assessment Practice

Use these tasks to simulate a backend assessment.

## Task 1: Order Service

Build a Spring Boot service with:

- create order endpoint;
- get order endpoint;
- SQL persistence;
- validation;
- consistent error responses;
- controller and repository tests.

Time box: 2-3 hours.

## Task 2: Secure API

Add JWT resource server security to an existing service.

Required:

- public health endpoint;
- authenticated read endpoint;
- write endpoint with authority check;
- CORS configuration;
- security tests.

Time box: 1-2 hours.

## Task 3: Event-Driven Flow

Add Kafka publishing and consuming for an order paid event.

Required:

- explicit event contract;
- producer with stable key;
- consumer with idempotency;
- retry or DLT plan;
- one integration test.

Time box: 3-4 hours.

## Evaluation Criteria

Review:

- code structure;
- correctness;
- tests;
- error handling;
- configuration quality;
- explanation of trade-offs.
