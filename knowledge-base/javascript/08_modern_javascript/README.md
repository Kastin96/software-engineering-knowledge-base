# Modern JavaScript

This section explains modern JavaScript features that make everyday code more
expressive, safer, and easier to maintain.

After finishing it, you should understand important ES6+ features, optional
chaining, nullish coalescing, iterators, generators, and symbols.

## Topics

- 01\. [ES6+ Features](es6_plus_features.md)
- 02\. [Optional Chaining](optional_chaining.md)
- 03\. [Nullish Coalescing](nullish_coalescing.md)
- 04\. [Iterators and Generators](iterators_generators.md)
- 05\. [Symbols](symbols.md)

## Suggested Learning Flow

Start with ES6+ features because they are used across modern JavaScript code.
Then learn optional chaining and nullish coalescing because they solve common
data-access and default-value problems. Finish with iterators, generators, and
symbols because they are more advanced but help explain how some JavaScript
protocols work.

## Mini Goal

By the end of this section, try to write a small script that:

- uses `const`, `let`, template literals, and arrow functions;
- safely reads nested API data with optional chaining;
- applies defaults with nullish coalescing;
- loops over a custom iterable;
- uses a symbol as a private-ish object key.
