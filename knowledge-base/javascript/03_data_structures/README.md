# JavaScript Data Structures

This section explains the most common JavaScript data structures and value
formats used in everyday code.

After finishing it, you should be able to store lists of values, model real
objects, choose between objects, maps, and sets, work with strings and dates,
read and write JSON, and use destructuring, spread, and rest syntax.

## Topics

- 01\. [Arrays](arrays.md)
- 02\. [Objects](objects.md)
- 03\. [Maps and Sets](maps_sets.md)
- 04\. [Strings](strings.md)
- 05\. [Dates](dates.md)
- 06\. [JSON](json.md)
- 07\. [Destructuring, Spread, and Rest](destructuring_spread_rest.md)

## Suggested Learning Flow

Start with arrays and objects because they are the most common structures in
JavaScript. Then learn maps and sets for more specific use cases. After that,
study strings, dates, and JSON because they appear often in APIs and user input.
Finish with destructuring, spread, and rest syntax because they make data work
cleaner and more expressive.

## Mini Goal

By the end of this section, try to write a small script that:

- stores a list of users;
- updates one user without mutating the original object;
- removes duplicate tags with a set;
- formats a readable date;
- converts data to JSON and back;
- uses destructuring and spread syntax.
