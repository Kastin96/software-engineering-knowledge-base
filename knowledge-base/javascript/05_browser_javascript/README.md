# Browser JavaScript

This section explains how JavaScript works inside the browser.

After finishing it, you should be able to read and update the DOM, listen to
user events, handle forms, store small amounts of data in the browser, make
browser HTTP requests, and use common browser APIs safely.

## Topics

- 01\. [DOM](dom.md)
- 02\. [Events](events.md)
- 03\. [Forms](forms.md)
- 04\. [Storage](storage.md)
- 05\. [Fetch in the Browser](fetch_in_browser.md)
- 06\. [Browser APIs](browser_apis.md)

## Suggested Learning Flow

Start with the DOM because it is the page structure JavaScript interacts with.
Then learn events because they connect user actions to code. After that, study
forms and storage, which are common in real user flows. Finish with browser
`fetch` and browser APIs so you understand how pages communicate and use browser
features.

## Mini Goal

By the end of this section, try to build a small browser page that:

- renders a list of items;
- handles a form submit;
- validates user input;
- saves simple data to local storage;
- loads data from an API;
- shows an error message when something fails.
