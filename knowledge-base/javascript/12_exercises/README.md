# Exercises

This section contains JavaScript practice tasks.

The exercises are grouped by difficulty. Try to solve them before opening the
solutions file. The goal is to practice real problem shapes: transforming data,
validating input, handling async work, structuring functions, and avoiding
unnecessary mutation.

## Sections

- 01\. [Beginner](beginner.md)
- 02\. [Intermediate](intermediate.md)
- 03\. [Advanced](advanced.md)
- 04\. [Solutions](solutions.md)

## How To Practice

1. Read the task and expected behavior.
2. Write the function without looking at the solution.
3. Test it with the sample input.
4. Add one extra test case of your own.
5. Compare your version with the solution.

## Suggested Order

Start with beginner exercises if you are still building fluency. Move to
intermediate when arrays, objects, and async code feel comfortable. Use advanced
exercises to practice code organization and edge cases.
