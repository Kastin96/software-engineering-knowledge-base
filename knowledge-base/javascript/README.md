# JavaScript Learning Path

This section is a structured guide for learning and reviewing JavaScript.

It is written as practical documentation: simple explanations, small examples,
common mistakes, and short practice tasks. The goal is to build real language
understanding, not only memorize interview answers.

## How To Use This Section

Read the topics in order if you are learning JavaScript from the beginning.
If you are reviewing, use the section README files as checklists and jump into
the topics where you feel less confident.
