# JavaScript Language Basics

This section introduces the basic building blocks of JavaScript.

After finishing it, you should be able to read simple JavaScript programs,
write small scripts, understand basic values and variables, use conditions and
loops, and create reusable functions.

## Topics

- 01\. [Syntax](syntax.md)
- 02\. [Variables](variables.md)
- 03\. [Data Types](data_types.md)
- 04\. [Operators](operators.md)
- 05\. [Control Flow](control_flow.md)
- 06\. [Functions](functions.md)

## Suggested Learning Flow

Start with syntax and variables. Then learn data types and operators. After
that, study control flow and functions, because they allow you to write useful
program logic.

## Mini Goal

By the end of this section, try to write a small program that:

- stores information about a user;
- checks whether the user is active;
- calculates a simple value;
- prints a readable message;
- uses at least one function.
