# Java Learning Path

This section is a structured guide for learning and reviewing core Java.

It focuses on the Java language, the standard library, the JVM basics, build
tools, testing, practical examples, exercises, and quick reference notes. It
does not cover Spring, databases, or reactive programming directly; those topics
belong in separate backend-focused sections.

## Version Note

The examples in this section avoid preview features and target modern Java that
is realistic for backend work. Java 17 and Java 21 are still common in production
systems, while Java 25 is the newer long-term support release. Java 26 is a
feature release. When a topic depends on a specific Java version, the file should
say so explicitly.

## How To Use This Section

Read the topics in order if you are building Java fundamentals. If you are
reviewing for interviews, use the section README files as checklists and jump to
weak areas.

Each topic should include:

- a practical explanation;
- realistic Java code;
- common mistakes;
- interview-style questions;
- short practice tasks.

## What This Section Should Prepare You For

After finishing the Java section, you should be able to:

- read and write small Java programs confidently;
- explain core language concepts in interview-friendly language;
- understand object-oriented Java code;
- use common standard library APIs;
- reason about basic JVM behavior;
- write testable Java code;
- prepare for Spring, database, and reactive Java topics.
