# Java Exercises

This section contains Java practice tasks.

Try to solve each task before opening the solutions file. The exercises focus on
real problem shapes: validation, collections, exceptions, files, streams,
testing, and small service design.

## Sections

- 01\. [Beginner](beginner.md)
- 02\. [Intermediate](intermediate.md)
- 03\. [Advanced](advanced.md)
- 04\. [Solutions](solutions.md)

## How To Practice

1. Read the task and expected behavior.
2. Write the code without looking at the solution.
3. Add at least two of your own test cases.
4. Compare your version with the solution.
5. Refactor names and structure after it works.

## Suggested Order

Start with beginner exercises if Java syntax and collections are still new. Move
to intermediate when OOP, exceptions, and streams feel comfortable. Use advanced
exercises to practice boundaries, dependencies, and concurrency.
