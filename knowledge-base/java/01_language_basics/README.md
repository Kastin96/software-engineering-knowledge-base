# Java Language Basics

This section introduces the basic building blocks of Java.

After finishing it, you should be able to read simple Java programs, write small
console applications, understand values and variables, use conditions and loops,
and create reusable methods.

## Topics

- 01\. [Syntax](syntax.md)
- 02\. [Variables](variables.md)
- 03\. [Data Types](data_types.md)
- 04\. [Operators](operators.md)
- 05\. [Control Flow](control_flow.md)
- 06\. [Methods](methods.md)

## Suggested Learning Flow

Start with syntax and variables. Then learn data types and operators. After
that, study control flow and methods, because they let you express real program
logic.

## Mini Goal

By the end of this section, write a small Java program that:

- stores information about a user;
- checks whether the user is active;
- calculates a simple score or total;
- prints a readable message;
- moves repeated logic into at least one method.

## Interview Readiness

You should be able to answer:

- What is the minimal structure of a Java program?
- What is the difference between a primitive type and a reference type?
- When would you use `var`, and when would you avoid it?
- Why should business logic usually be moved out of `main`?
- How do `if`, `switch`, `for`, and `while` differ in everyday code?
