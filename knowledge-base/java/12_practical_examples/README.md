# Java Practical Examples

This section contains practical Java examples that combine multiple core topics
into realistic tasks.

The examples are intentionally small. Each one shows a useful problem shape,
clean code, and a short explanation of what the code demonstrates.

## How To Use This Section

Read one example, copy the idea into a scratch file, then change the
requirements. The point is not to memorize exact code. The point is to recognize
common shapes: validation, transformation, I/O boundaries, service dependencies,
and controlled concurrency.

## Mini Goal

After this section, build one small console program that:

- reads input from a file or hardcoded list;
- validates the data;
- transforms it into response records;
- handles errors clearly;
- has at least one unit-testable service method.
